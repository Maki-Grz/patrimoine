# Patrimoine - Frontend UI 🇪🇺

This directory contains the user interface of the **Patrimoine** application, built using **Svelte 5** and **SAP UI5 Web Components / Fiori Design**.

## Development Setup

The frontend is served via [Vite](https://vite.dev/). 

Before starting, ensure you have installed the project-wide dependencies.

1. **Install UI dependencies**:
   ```bash
   npm install
   ```

2. **Run in development mode**:
   ```bash
   npm run dev
   ```
   *This starts the local Vite dev server (typically at http://localhost:5173).*

For backend integration, domain models, execution logic, and full architecture descriptions, please refer to the **[Root README.md](../README.md)**.
