# Security Policy 🛡️

We take the security and privacy of your personal financial data very seriously. As a self-hostable, sovereign financial manager, we want to ensure the codebase remains highly secure and robust.

---

## Supported Versions

Patrimoine has graduated from beta into **General Availability (GA)**. We actively support and maintain the latest stable releases. 

| Version | Supported |
| ------- | --------- |
| `1.0.x` | Yes (Active GA Release) |
| `< 1.0.0` | No (Pre-release / Beta versions superseded) |

---

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability, we ask that you report it privately so we can address it before public disclosure. You can report vulnerabilities in one of the following ways:

1. **GitHub Private Vulnerability Reporting**: Go to the Security tab of the repository on GitHub, click "Vulnerability reporting", and select "Report a vulnerability".
2. **Email**: If you prefer direct contact, send an email to `security-patrimoine@proton.me` (or your preferred security email address). If possible, please sign/encrypt your message using a PGP key.

### What to Include in a Report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the vulnerability (or a proof-of-concept exploit).
- The environment and configuration in which it was found.

---

## Our Commitment

Upon receiving a private security report, we commit to:
- Acknowledging receipt of the report within **48 hours**.
- Working closely with the reporter to investigate and verify the vulnerability.
- Providing a resolution timeframe (usually aiming for a patch within **30 days** of validation).
- Coordinating a public disclosure if necessary, giving full credit to the reporter for their responsible disclosure.
